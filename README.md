# Full Stack Development Internship - Project 2: Backend API Development 
# 🚀 Backend API Development

A simple backend API project built with **Node.js** and **Express.js**. This project helps manage data, connect to a database, and handle requests from the frontend.

---

## 📌 About

This project is created to learn and practice backend development. It includes API creation, database connection, authentication, and basic CRUD operations using clean and organized code.

---

## ✨ Features

* Create REST APIs
* Add, view, update, and delete data (CRUD)
* Connect to a database
* User login and signup
* JWT authentication
* Password encryption
* Error handling
* Clean folder structure
* Easy to understand code

---

## 🛠️ Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcrypt
* Postman
* Git & GitHub
* Visual Studio Code

## 🚀 Getting Started

### Clone the project

```bash
git clone https://github.com/your-username/backend-api.git
```

### Install dependencies

```bash
npm install
```

### Start the server

```bash
npm start
```
